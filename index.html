VibeSetup.

One prompt. Any machine. Cursor, Devin, OpenClaw, and Claude install the same pinned kit and run like objective runners — not chatbots that forget the company every morning.

Paste this. The agent reads your OS and the tool you are in. It pins the kit, writes a tiny frozen constitution, and turns on a capped Ralph loop. After that you only give objectives.

        Detailed Description
        
What you actually get.


        

          
1

          

            
How agents ship

            
Superpowers

            
You get a working way to ship with an agent instead of chatting in circles. Superpowers is a software methodology: clarify the idea, write a plan, fail a test first, implement, then verify before anyone says done. Cursor loads it as a skill when you ask for a feature. Claude Code installs it as a plugin. Devin should be pointed at the same rules in Knowledge so it cannot skip tests. OpenClaw keeps a short AGENTS.md and opens the skill only when building. The point is not a louder personality. The point is the agent cannot honestly call the work finished until the checks pass. Use this as the only methodology pack — a second TDD skill will fight it.

          

        


        

          
2

          

            
Production engineering skills

            
Agent Skills

            
You get production engineering habits packaged for agents: security, CI, observability, shipping, docs, and UI engineering. This is the specialty toolkit, not a second methodology. Cursor copies skills into .cursor/skills and only opens the one that matches the task. Claude uses the same files. Devin Knowledge should link to those files, not paste the essays. OpenClaw loads the folder through extraDirs or workspace skills. A vibe coder gets a security pass and a real pipeline without becoming a staff engineer overnight. When the task is add login, the agent should open the security skill, not the whole pack. Keep Superpowers as the loop. Let this pack own CI, observability, and shipping reviews. Do not paste these bodies into always-on rules. That wrecks prompt cache and raises the bill.

          

        


        

          
3

          

            
Clarify requirements first

            
Grill Me

            
You get one hard interview before any code. grill-me asks what done means until it is specific enough to test. That interview becomes a short spec on disk. Cursor runs it once per capability. Claude Code uses the skill when you start a feature. Devin should ask the same questions in the first session and write the answers into the repo. OpenClaw stores the result in the workspace, not in chat. This is how you stop restating NFRs every morning. The agent cannot exceed a requirement that was never written. After grill-me you should have a file you can point at for the rest of the week. Skip a second interview pack. One grill is the exam.

          

        


        

          
4

          

            
Design and testing

            
Anthropic Skills

            
You get Anthropic's own examples for design and browser testing, plus the public Agent Skills spec. frontend-design fights generic AI UI. webapp-testing makes the agent click through the product instead of guessing. Cursor and Claude load those two skills on demand. Devin can use the testing skill as the definition of looks right. OpenClaw should not dump the whole examples repo into AGENTS.md. Only point at the skills you actually use. You are not installing Anthropic as your company. You are borrowing two files that raise the visual and test bar. This is how a vibe coder's app stops looking like a default dashboard. Leave the toy skills out of the always-on set.

          

        


        

          
5

          

            
Loop until done

            
Ralph

            
You get the outer loop. Skills teach how. Ralph keeps going. Each pass is a fresh context. Memory is git, prd.json, and progress.txt, not the chat window. Cursor uses a stop hook that sends the agent back until tests pass or max-iterations hits. Claude has an official Ralph plugin. Devin is already long-running: attach tests as the finish line. OpenClaw uses a heartbeat or standing order with a cap. Write stories to prd.json so a new context can pick the next incomplete item. Twelve iterations is enough for a capability. If it is still red, stop and read the failures. Always set a max. Uncapped Ralph is a money fire. This is the missing engine that turns a chat box into an objective runner you can leave running.

          

        


        

          
6

          

            
Catch store rejects

            
App Store

            
You get a pre-submit audit against Apple's review guidelines and the rejection patterns that kill first submissions: privacy, payments, incomplete features, misleading claims. Cursor and Claude load it when you say you are shipping to the store. Devin should run it before any ready-for-TestFlight claim. OpenClaw can run it on a heartbeat before release notes. Play Store risk is similar: incomplete listings, broken in-app purchase, missing account deletion. If you ship both stores, still start with this skill and add Play oracles to docs later. Skip this pack if you are not shipping a store binary. It does not create your privacy policy URL or developer account. It does stop you from walking into Guideline 2.1 and 5.1.1 with a smile.

          

        


        

          
7

          

            
Track agent spend

            
ccusage

            
You get a local picture of what agents are costing. ccusage reads logs from Claude, OpenClaw, and related tools so spend is visible without a mystery SaaS that rewrites your prompt. Cursor has its own usage UI; still run ccusage for CLI hosts. Combined with a tiny frozen AGENTS.md, prompt cache actually hits and repeated input drops to about a tenth. Devin spend lives in Devin's dashboard. Plan on a cheaper model, implement on a frontier model, and cap Ralph. A huge always-on rule file looks helpful and then silently doubles the bill because the cache prefix changes. VibeSetup keeps the constitution tiny so the expensive tokens are the work, not the lecture. That is the cost toolkit, not another skill dump at the top of the prompt.
